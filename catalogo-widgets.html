Catálogo de widgets — folleto-widgets.js

Cada widget de abajo está demostrado en vivo: esta página carga el js/folleto-widgets.js real del proyecto, así que lo que ves aquí es exactamente lo que sale en las 12 actividades. Debajo de cada demo hay un botón Validar (cuando el widget se autocalifica) y el código exacto para usarlo. Todo el JS es nativo, sin jQuery.

"Encierra" una o varias tarjetas de texto entre varias opciones. 2. Verdadero o Falso

folletoVerdaderoFalso se autocalifica

Cada enunciado en su propia franja de color con una píldora V/F a la derecha. Un enunciado sin responder cuenta como incorrecto (se pinta de rojo, no se deja neutro). items: [{enunciado, correcta: 'V'|'F'}]. colores (opcional, 3er parámetro): array [{bg,border}] para fijarlos a mano; si no se pasa, se generan al azar. opciones.justificacion (4to parámetro, opcional): agrega un campo de texto debajo de cada afirmación para que el estudiante explique su respuesta — false (default, sin campo), true (todas lo llevan) o 'soloFalsos' (solo las afirmaciones falsas, el caso típico de "si es falso, explica"). También se puede fijar por ítem con item.justificacion.

Sin justificación (comportamiento original)

sin calificar

Con justificación en todas las afirmaciones

sin calificar 
var items = [
  { enunciado: 'El reciclaje ayuda a reducir la contaminación.', correcta: 'V' },
  { enunciado: 'Toda la basura orgánica tarda lo mismo en descomponerse que el plástico.', correcta: 'F' },
  { enunciado: 'Separar la basura facilita su reciclaje.', correcta: 'V' },
];
folletoVerdaderoFalso(items, 'p1act');

function pregunta1() {
  let core = folletoValidarVerdaderoFalso('p1act');
  document.getElementById('pre1a').value = (core * 2).toFixed(2);
}

// con campo de justificación bajo TODAS las afirmaciones (V y F)
folletoVerdaderoFalso(items, 'p1act', null, { justificacion: true });

// variante: solo bajo las falsas ("si es falso, explica")
folletoVerdaderoFalso(items, 'p1act', null, { justificacion: 'soloFalsos' });

3. Unir con líneas

folletoUnirLineas se autocalifica

Dos columnas: clic en un ítem de la izquierda y luego en el de la derecha que le corresponde, y se dibuja una línea real (SVG) entre ambos — doble clic sobre un ítem ya unido deshace esa unión. El par correcto es items[i].literal con items[i].enunciado (mismo índice); la columna derecha se mezcla sola. opciones.tituloIzquierda / opciones.tituloDerecha (4to parámetro, ambos opcionales): rótulo encima de cada columna, como "Causa"/"Efecto" en el PDF — si no se pasa ninguno, no aparece fila de títulos (igual que antes). opciones.colorTituloIzquierda / opciones.colorTituloDerecha (opcionales): color de fondo de cada píldora, para calcar el color exacto del PDF; sin esto, ambas usan el mismo índigo por defecto.

Sin títulos (comportamiento original)

sin calificar

Con títulos de columna ("Causa" / "Efecto")

3.5. Asignar literal

folletoAsignarLiteral se autocalifica

Dos columnas SIN líneas: a la izquierda, tarjetas con su literal (a, b, c…) en un chip de color; a la derecha, cada descripción trae una casilla <select> donde el estudiante ELIGE la letra que le corresponde — para preguntas tipo "Lee los siguientes X y coloca el literal que corresponda a su Y", donde el PDF trae un cuadradito con la letra ya escrita a mano en vez de líneas trazadas. Las casillas de la derecha son todas del mismo gris neutro (no del color de su literal correcto): colorearlas según la respuesta delataría la solución con solo mirarlas. izquierda: [{ literal, texto }]. derecha: [{ texto, correcta }], donde correcta es el literal esperado.

sin calificar 
var izquierda = [
  { literal: 'a', texto: 'Separar los residuos en orgánicos e inorgánicos.' },
  { literal: 'b', texto: 'Reducir el uso de plásticos de un solo uso.' },
  { literal: 'c', texto: 'Reutilizar envases de vidrio para almacenar alimentos.' },
];
var derecha = [
  { texto: 'Permite que cada tipo de residuo tenga un destino adecuado.', correcta: 'a' },
  { texto: 'Disminuye la cantidad de basura que termina en el ambiente.', correcta: 'b' },
  { texto: 'Alarga la vida útil de un envase antes de desecharlo.', correcta: 'c' },
];
folletoAsignarLiteral(izquierda, derecha, 'p1act');

function pregunta1() {
  let core = folletoValidarAsignarLiteral('p1act');
  document.getElementById('pre1a').value = (core * 1.5).toFixed(2);
}

4. Ordenar / secuencia (arrastrar)

folletoOrdenarSecuencia se autocalifica (modo fijo)

Lista arrastrable con Pointer Events (mouse, táctil y lápiz — sin jQuery UI); se agarra desde cualquier parte de la tarjeta (no solo el ícono ⠿⠿) y sigue al cursor en vivo mientras los demás se corren con una animación suave para abrir espacio. Por defecto (modoRango: false) cada oración conserva su letra/id fija sin importar dónde se arrastre: sirve para "ordena para que tenga sentido" con una única secuencia correcta. Con modoRango: true la insignia se convierte en un rango por posición (1, 2, 3…) que se recalcula al soltar — para "coloca 1 en el más urgente, 3 en el menos" (R.A., sin orden único).

Modo fijo · una secuencia correcta

sin calificar

modoRango · ranking (R.A.)

var pasos = [
  { id: 'A', texto: 'Separar los materiales reciclables.' },
  { id: 'B', texto: 'Llevarlos al contenedor correspondiente.' },
  { id: 'C', texto: 'Lavar los envases antes de reciclarlos.' },
];

// modo fijo (default): existe UN orden correcto
folletoOrdenarSecuencia(pasos, 'p1act');
function pregunta1() {
  // el orden correcto se define por el ID de cada paso, no por su posición inicial
  let core = folletoValidarOrdenarSecuencia(['C', 'A', 'B'], 'p1act');
  document.getElementById('pre1a').value = (core * 2).toFixed(2);
}

// modoRango: ranking por posición, sin orden único (R.A.)
folletoOrdenarSecuencia(pasos, 'p2act', { modoRango: true });

folletoTabla mixta: libre y/o se autocalifica

Tabla con columnas de color y celdas fijas, editables (R.A.) o autocalificadas, celda por celda. Cada celda puede ser: un string/number (fijo), null (campo abierto), {resp} (se autocalifica), {campo:'pNcampoTexto'} (fuerza un campo tipo cuaderno específico), o {texto,bg,color,rowspan?,colSpan?} (celda-etiqueta fusionable). sinEncabezado omite el <thead>; anchosCol fija el ancho de cada columna.

Abierta (R.A.) — campo tipo cuaderno

Con columna autocalificada

sin calificar

Sin encabezado + colSpan/rowspan + anchosCol

// fusionada verticalmente (rowspan), más anchos de columna fijos

folletoValidarExactas se autocalifica

Versión nativa del validarExactas del framework viejo: no dibuja nada, valida campos que ya pusiste en el HTML con ids seguidos (p1num0, p1num1…). Recibe las respuestas en el mismo orden y el prefijo del id (con o sin #). Lee el value de input / textarea / select, o el texto si es un div (esDiv). Ignora mayúsculas, tildes y espacios de más; cada respuesta puede ser un array de alternativas. Pinta .bien / .mal y los limpia al volver a escribir.

Ordena del 1 al 3

sin calificar 
// HTML: <input id="p1num0"> <input id="p1num1"> ... (ids seguidos)
function pregunta1() {
  let core = folletoValidarExactas(['2', '1', '3'], '#p1num');   // 0 a 1
  document.getElementById('pre1a').value = (core * 5).toFixed(2);
  return core * 5;
}
// alternativas aceptadas y lectura de un div:
folletoValidarExactas([['Golgi', 'aparato de Golgi'], 'núcleo'], 'p2resp', true);

6. Texto y lectura

folletoLectura

Recuadro de un texto para leer: título + párrafos + cita, con imagen(es) opcional(es) flotantes. config: {titulo, imagen, parrafos, cita, clase} — cada párrafo puede ser un string simple o {texto, imagen} si ESE párrafo en particular lleva su propia imagen. 

folletoLectura({
  titulo: '¿Por qué reciclar cambia el futuro?',
  parrafos: [
    'Cada año se producen millones de toneladas de residuos que podrían reutilizarse. Reciclar no solo reduce la basura: también ahorra energía y agua.',
    'Separar los materiales en casa es el primer paso de una cadena que termina dándoles una segunda vida útil.',
  ],
  cita: 'Adaptado de un artículo de divulgación ambiental, 2024.',
}, 'p1lectura');

folletoRespuestasNumeradas R.A., no se autocalifica

Filas de respuesta abierta con un número grande de color a la izquierda. n: cuántas filas. campoClass: la clase p{N}campoTexto que fija el alto del campo (el número es la ALTURA en filas, no el número de la pregunta). 

// 3 respuestas abiertas, cada campo de 2 filas de alto
folletoRespuestasNumeradas(3, 'p2act', 'p2campoTexto');

7. Multimedia

folletoSubirImagen

Recuadro para subir una imagen (JPEG/PNG, máx. 3 MB) con vista previa — para "¿Cómo se ve?", "Dibújalo y súbelo", etc. fileNum debe ser único por página si hay más de un subir-imagen. label (opcional): píldora de texto debajo del recuadro. 

folletoSubirImagen(1, 'p6img', '¿Cómo se ve?');
// HTML: solo el contenedor vacío, ej. <div id="p6img"></div>

folletoLienzo

Mini "Paint": lápiz libre, línea, rectángulo, círculo, borrador, colores, grosor y relleno — para "diseña/dibuja un esquema" cuando un campo de texto no alcanza. Funciona con Pointer Events (mouse, táctil y lápiz). config: {alto, colores}, ambos opcionales. 

folletoLienzo('p7lienzo', { alto: 260 });
// HTML: solo el contenedor vacío, ej. <div id="p7lienzo"></div>

8. Insignias

folletoBadgeLectura

Círculo de color + letra + texto, para encabezar preguntas de comprensión lectora. tipo: 'literal', 'inferencial' o 'critica'. 

folletoBadgeLectura('literal', 'badgeL1');
folletoBadgeLectura('inferencial', 'badgeI1');
folletoBadgeLectura('critica', 'badgeC1');
// HTML: solo el contenedor vacío, ej. <div id="badgeL1"></div>

folletoTituloSeccion

Títulos de sección de Creando juntos calcados del PDF: círculo con ícono (img/ico_sec_*.png) sobre una píldora de color con borde punteado y texto blanco; "Paso a paso" y "Recursos" van con su ícono suelto y el texto de color. La píldora y el texto son HTML/CSS (nítidos, responsive e imprimibles). Tipos: sumergete, entrana, imaginacion, daforma, prueba, pasoapaso, recursos. Opcional { texto } para otro rótulo. 

// HTML: <div id="tSumergete" class="mb-3"></div> (contenedor vacío)
folletoTituloSeccion('sumergete', 'tSumergete');
folletoTituloSeccion('entrana', 'tEntrana');
folletoTituloSeccion('imaginacion', 'tImaginacion');
folletoTituloSeccion('daforma', 'tDaforma');
folletoTituloSeccion('recursos', 'tRecursos');
folletoTituloSeccion('pasoapaso', 'tPasoapaso');
folletoTituloSeccion('prueba', 'tPrueba');
